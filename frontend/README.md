# Skill Sphere - Frontend (React + Vite + MUI)

## Setup

1.  **Install Dependencies:**
    ```bash
    npm install
    ```

2.  **Setup Environment Variables:**
    *   Copy `.env.example` to `.env`.
    *   Ensure `VITE_API_URL` points to your running backend API (default is `http://localhost:3000/api`).

3.  **Run the Development Server:**
    ```bash
    npm run dev
    ```
    The frontend should start, typically on `http://localhost:5173` (or the next available port). Open this URL in your browser.

## Available Scripts

*   `npm run dev`: Start the Vite development server.
*   `npm run build`: Build the application for production.
*   `npm run lint`: Lint the code.
*   `npm run preview`: Preview the production build locally.
