# Skill Sphere - Personal Skill Tracking Application

This project helps individuals track their progress in various skills.

## Project Structure

*   `/backend`: NestJS API server (handles data, logic, authentication).
*   `/frontend`: React/Vite client application (user interface).

## Setup & Running

1.  **Backend Setup:** Navigate to the `/backend` directory and follow the instructions in `backend/README.md`. Start the backend server.
2.  **Frontend Setup:** Navigate to the `/frontend` directory and follow the instructions in `frontend/README.md`. Start the frontend development server.
3.  **Access:** Open the frontend URL (usually `http://localhost:5173`) in your browser.

## Requirements

*   Node.js (v18 or later recommended)
*   npm or yarn
*   A running PostgreSQL database (or modify `schema.prisma` and `DATABASE_URL` for a different database like SQLite).

See individual README files in `/backend` and `/frontend` for more details.
